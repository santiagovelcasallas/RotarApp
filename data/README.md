# data/

- `raw/`: descargas originales (no se versiona).
- `interim/`: datos armonizados a la rejilla común (no se versiona).
- `processed/`: resultados finales livianos que consume la app (sí se versiona si pesa poco).
- `referencia/`: tablas de cultivos, plagas, precios y polígonos IGAC que el modelo lee directamente (sí se versiona). Ver [referencia/README.md](referencia/README.md).

Fuentes y reglas en [../docs/datos.md](../docs/datos.md).
